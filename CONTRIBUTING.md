# Contributing

1. Open or select a GitHub Issue and describe the intended change.
2. Fork this public repository and create a topic branch.
3. Implement the change and run the README build/test commands.
4. Open a pull request linked to the Issue. Fill in the PR template.
5. Address review comments and wait for the owner's merge decision.

External contributors do not need access to the original private repository.
Do not request write access to main. Keep rendering comparisons deterministic:
record camera, time, seed, resolution and renderer. Changes to assets must include
updated packed resources so a clean checkout remains runnable.
